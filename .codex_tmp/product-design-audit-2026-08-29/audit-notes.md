# Atlas 项目总览 UI / UX 审计

## 审计范围

- 页面：项目总览
- 用户目标：快速判断项目健康度、识别需要行动的事项，并进入具体项目处理
- 证据：当前运行页面的桌面端、趋势图交互态与移动端截图

## 总体判断

当前页面视觉干净、状态色克制，基础信息架构已经成立，但更像“数量展示页”，还不是“工程决策工作台”。优先级最高的改进不是再加更多卡片，而是把项目健康度、待办异常和数据完整性放到首屏，并让统计卡片、图表和最近动态都能继续筛选或钻取。

## 审计步骤

1. 桌面端总览：一般。结构清楚，但首屏信息密度偏低，缺少行动入口与对比口径。
2. 趋势图交互：需改进。数据点支持焦点提示，但最右侧提示被容器裁切；14 个点都进入键盘焦点顺序，操作成本偏高。
3. 移动端首屏：一般。布局能纵向重排，但项目列表占据首屏大部分空间，核心总览与风险信息被推到下方。

## 主要发现

### 优点

- 进行中、已完成、电芯总数使用一致的卡片语言，状态色易于区分。
- 最近创建项可以直接进入对应实验，形成了基本的钻取路径。
- 趋势数据点提供 `aria-label` 和键盘焦点，说明已有可访问性意识。
- 900px 与 600px 断点能将侧栏和卡片自动改为单列，未出现横向溢出。

### UX 风险

- 三个指标只有当前值，没有时间范围、环比、口径说明，也不可点击，用户无法解释“2 / 0 / 5”意味着变好还是变坏。
- “实验增长趋势”展示累计值，曲线天然只升不降，对判断近期产出、停滞或吞吐帮助有限。
- “最近创建”只记录创建事件，无法回答谁完成了步骤、哪里被取消、哪个项目长期无进展。
- 页面缺少“需要我处理”的行动层，例如未分配负责人、长期 Planned、缺少设备/配方/测试项、谱系不完整。
- 桌面端主要内容集中在上半区，仍有较大的空白区域，可以承载风险列表或项目健康表。
- 移动端项目列表先于总览，用户需要滚动较长距离才能看到核心数据。

### 可访问性风险

- 趋势图最右侧 tooltip 被 `overflow: hidden` 裁切，导致数值不可完整读取。
- 图表 14 个数据点全部可聚焦，会增加键盘用户的 Tab 次数；建议让图表作为一个整体聚焦并支持方向键切换数据点。
- 多个仅图标按钮在视觉上缺少文字解释；DOM 中部分按钮只暴露图标字形，需确认都有稳定的 `aria-label` 与可见焦点样式。
- 截图只能确认视觉与部分 DOM 结构，尚未验证实际对比度、屏幕阅读器朗读、完整键盘顺序和 200% 缩放。

## 推荐的信息架构

### 第一层：健康摘要

- 活跃项目
- 本周完成步骤 / 与上周对比
- 待处理异常
- 数据完整率

统计卡片应可点击，并带时间口径与微型趋势，例如“本周完成 8，较上周 +3”。

### 第二层：行动区

- `需要关注`：无负责人、超过阈值仍 Planned、缺设备/配方、缺测试项、谱系断点
- 每条展示对象编号、原因、负责人、停留时长和直接处理入口

### 第三层：趋势与分布

- 默认用“每周新增实验 / 完成步骤”替代纯累计曲线
- 提供 14 天 / 30 天 / 90 天切换
- 增加按项目或负责人分组
- 保留累计值作为次级开关

### 第四层：最近动态

- 合并创建、完成、取消、状态变更、负责人变更
- 支持“全部 / 我的 / 异常”筛选

## 可直接使用的现有数据维度

- 步骤状态分布与完成率：`ExperimentStep.status`
- 本周吞吐与周期时间：`started_on`、`completed_on`
- 待分配负责人：`ExperimentStep.owner`
- 数据完整性：步骤描述、设备、配方、原料用量、测试项目、样品—电芯关联
- 追溯完整性：父子步骤链接、原材料使用、电芯样品来源
- 人员负载：负责人名下 Planned / Completed 步骤数
- 设备使用：设备关联步骤数与近期使用次数

当前样例数据已经显示出行动价值：18 个步骤中 16 个仍为 Planned，12 个未分配负责人，17 个未关联设备，18 个缺少配方，5 个电芯全部缺测试项目，4 个电芯没有样品来源关联。

## 需要新增字段后再做的维度

- 计划完成日期 / SLA：用于真正识别逾期与风险
- 优先级：用于工作队列排序
- 里程碑或实验阶段：用于跨项目对齐进度
- 实验结论 / 成功标准 / 结果评级：用于从“记录过程”升级到“评估结果”

## 建议实施顺序

1. 修复趋势图 tooltip 裁切与键盘交互；让三张统计卡片可钻取。
2. 首屏增加“需要关注”列表，并先使用现有字段构建数据完整率。
3. 将累计趋势改为吞吐趋势，增加时间范围和分组筛选。
4. 再评估是否新增计划日期、优先级和结果评级字段；涉及数据库迁移。
